# Test dependencies for LOCAL use.
#
# pytest-homeassistant is Home Assistant's own test plugin and pulls in the
# Home Assistant release of the same version. It replaces
# pytest-homeassistant-custom-component, which ended with Home Assistant
# 2026.10; the two must not be installed together.
#
# Deliberately UNPINNED here: locally you want whatever is current, and only a
# current Home Assistant surfaces deprecations and API removals - an old pin
# makes the integration look healthy while it is already broken (the previous
# pin, 0.13.254, held Home Assistant 2025.6 while users ran 2026.8). Its betas
# are pre-releases, so pip leaves them out.
#
# The CI test job does NOT install this file: its minimum job needs the old
# plugin, pinned to the minimum Home Assistant. See .github/workflows/test.yaml.
pytest-homeassistant
# Declared rather than inherited: it arrives through the plugin above today,
# and the e2e tests rely on `pytest.mark.timeout`. The day that transitive
# dependency changes, a marker nothing registers becomes a silent no-op.
pytest-timeout
# check.sh runs the suite with --cov. The old test plugin brought it along,
# the new one does not.
pytest-cov
# The gates check.sh runs, at the versions CI pins - a formatter that
